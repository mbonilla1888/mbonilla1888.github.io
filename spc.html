Statistical Process Control (SPC)

Automation of SPC analysis for optical and semiconductor manufacturing.

Problem

Traditional SPC tools struggled with spectral data, custom control limits, and multi-run optical datasets.

Solution

  • Python-based SPC framework
  • X̄–R charts customized for spectral minima
  • Static and warning control regions
  • Automated reflection averaging across wavelength bands

Impact

  • Early detection of wavelength drift
  • Reduced false positives vs textbook SPC
  • Improved decision-making during production runs

Next

This framework later fed into MES dashboards, automated alerts, and standardized review cadence.
