Statistical Process Control (SPC) automation & data visualization using Python

SPC monitors processes so they remain within operational boundaries. Traditional SPC often requires specialized software (e.g., Minitab). By using Python, I can:

  • Eliminate SPC license dependency (cost reduction)
  • Automate statistics + Western Electric (WECO) rules directly from data sources (time savings, less human error)
  • Generate automatic alerts when warning or control limits are hit (faster corrective action)
  • Customize visualizations for fast executive and cross-team status clarity

Below are two examples: spectral monitoring in optics and thickness monitoring in semiconductors.

SPC for Spectral Monitoring (Optics)

  • Plots spectral data for selected dates or run numbers.
  • Overlays reflection requirements (horizontal dashed line) and wavelength regions (vertical dashed lines).
  • Automatically tags runs as Warning or Out-of-limits based on defined thresholds.

Example requirements used in this illustration: Ravg < 3.0% (390–490nm) and Ravg < 3.0% (670–720nm).

Minima shift tracking (within a control region)

  • Focuses on the 390–490nm region.
  • Tracks minima by run to monitor centering wavelength and coating performance.
  • Can be configured to monitor minima, Ravg, or any derived metric.

Automated alerts

  • Email alert auto-generated when warning or control limits are reached.
  • Includes run identification and the out-of-limit value for quick response.

SPC for thickness monitoring (Semiconductors)

  • Uses 5 measurement points per sample to compute the sample average (X chart).
  • Calculates and plots UCL/LCL based on data spread.

Range chart (R chart)

  • Computes and plots range per sample (R chart) to capture variation.

Box plot visualization

  • Visualizes how the average stacks against each measurement distribution.
  • Can be extended to moving range and process capability (Cpk), etc.

How this ties into MES & operations

  • SPC outputs can feed dashboards, shift summaries, and automated notifications.
  • Reduces manual reporting and standardizes decision-making across teams.
